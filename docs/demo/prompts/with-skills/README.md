# Prompts with Skill Injection

Short prompts paired with an explicit skill reference. Use these when the agent's default behavior isn't structured enough and you want to steer it with a demo skill.

Format:

```markdown
## Prompt
<paste in UI>

## Why the skill
<when and why to inject>

## If the agent ignores the skill
<recovery nudge>
```

Skills live in [../../skills/](../../skills/).
