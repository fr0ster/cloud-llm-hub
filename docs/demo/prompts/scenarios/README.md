# Dialog Scenarios

Each file is a starter prompt for a demo conversation. The AI drives the subsequent turns; the facilitator only intervenes if the agent stalls or hallucinates.

Format:

```markdown
# <Scenario title>

## Opening prompt
<one short prompt to paste>

## Facilitator notes
<what AI is expected to do next; when to nudge>
```

Use alongside [../quick/](../quick/) (single-turn prompts) and [../with-skills/](../with-skills/) (skill injection examples).
