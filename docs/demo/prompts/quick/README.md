# Quick Prompts

Short one-shot prompts for live demos. Each file is a single prompt (1-3 lines) intended to show one capability per turn.

Numbering (`01-`, `02-`, ...) suggests a natural demo order within each theme — but prompts are self-contained; feel free to skip or reorder.

## Themes

- [discovery/](discovery/) — exploring unfamiliar SAP systems
- [analysis/](analysis/) — reading and explaining code
- [security/](security/) — quick security checks
- [development/](development/) — scaffolding and code generation
