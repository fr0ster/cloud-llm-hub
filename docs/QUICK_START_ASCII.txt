┌─────────────────────────────────────────────────────────────────────────┐
│ КРОК 2: Налаштувати Cline (2 хвилини)                                  │
└─────────────────────────────────────────────────────────────────────────┘

  2.1. Відкрити Cline MCP Settings:
       VS Code: Ctrl+Shift+P → "Cline: Edit MCP Settings"
       
  2.2. Додати конфігурацію:
  
  ┌─────────────────────────────────────────────────────────────────────┐
  │ {                                                                   │
  │   "mcpServers": {                                                   │
  │     "cloud-llm-hub": {                                              │
  │       "type": "sse",                                                │
  │       "endpoint": "http://localhost:4004/mcp/stream/sse",          │
  │       "headers": {                                                  │
  │         "Authorization": "Basic YWxpY2U6"                           │
  │       }                                                             │
  │     }                                                               │
  │   }                                                                 │
  │ }                                                                   │
  └─────────────────────────────────────────────────────────────────────┘
  
  💡 Або скопіюй готовий: docs/examples/cline-sse-dev.json

┌─────────────────────────────────────────────────────────────────────────┐

  ┌─────────────────────────────────────────────────────────────────────┐

┌─────────────────────────────────────────────────────────────────────────┐
│ 🐛 Troubleshooting                                                      │
└─────────────────────────────────────────────────────────────────────────┘

  ❌ Проблема: Cline не бачить MCP сервер
  ✅ Рішення:
     1. Перевір endpoint: http://localhost:4004/mcp/stream/sse
     2. Перевір Authorization: Basic YWxpY2U6
     3. Reload Window (Ctrl+Shift+P)

  ❌ Проблема: Connection refused
  ✅ Рішення:
     curl http://localhost:4004/mcp/Health
     Якщо не працює → запусти: cds watch --profile development

  ❌ Проблема: 401 Unauthorized
  ✅ Рішення:
     Перевір Authorization header:
     echo -n "alice:" | base64  # Має бути: YWxpY2U6

  ❌ Проблема: 502 Bad Gateway (upstream)
  ℹ️  Це нормально! Backend mcp-abap-adt не запущений.
     Авторизація працює, але немає upstream сервера.
     Запусти backend:
     cd external/mcp-abap-adt && npm install && npm start
