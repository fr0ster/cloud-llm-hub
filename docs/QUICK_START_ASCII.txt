┌─────────────────────────────────────────────────────────────────────────┐
│ 🐛 Troubleshooting                                                      │
└─────────────────────────────────────────────────────────────────────────┘

  ❌ Issue: Cline cannot see the MCP server
  ✅ Fix:
    1. Endpoint must be http://localhost:4004/mcp/stream/sse
    2. Authorization: Basic YWxpY2U6
    3. Reload Window (Ctrl+Shift+P)

  ❌ Issue: Connection refused
  ✅ Fix:
    curl http://localhost:4004/mcp/Health
    If it fails → start: cds watch --profile development

  ❌ Issue: 401 Unauthorized
  ✅ Fix:
    Check the Authorization header:
    echo -n "alice:" | base64  # Expected: YWxpY2U6

  ❌ Issue: 502 Bad Gateway (upstream)
  ℹ️  Normal while the mcp-abap-adt backend is offline.
    Auth works, but there is no upstream server.
    Start the backend:
    cd external/mcp-abap-adt && npm install && npm start
