---
name: customer-namespace-only-in-section-7
description: Section 7 (custom program objects) of the spec lists only objects in the SAME namespace as the documented object. Standard SAP code and other Z-namespaces are excluded — they belong in sections 5/6 (interfaces / dependencies) or nowhere. Use the object's package and namespace prefix from `SearchObject` to filter; never assume by name alone.
