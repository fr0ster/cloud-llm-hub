description: 'Metadata extension rules — Fiori UI annotations layered on a projection CDS view. Shape: `@Metadata.layer: #CUSTOMER` (or #PARTNER), `annotate view Z##_C_<ROOT> with { @UI.facet: [{ id: ''Identification'', type: #IDENTIFICATION_REFERENCE, position: 10 }, { id: ''Plants'', type: #LINEITEM_REFERENCE, targetElement: ''_Plant'' }] @UI.hidden: true Uuid; @UI.lineItem: [{ position: 10 }] @UI.identification: [{ position: 10 }] @UI.selectionField: [{ position: 10 }] Matnr; … }`. The projection view must have @Metadata.allowExtensions: true (otherwise "extension layer not allowed"). Hide technical fields (@UI.hidden: true on Uuid, RootUuid, audit fields). Facet types — #IDENTIFICATION_REFERENCE for the general section, #LINEITEM_REFERENCE with targetElement for a child table on the object page, #FIELDGROUP_REFERENCE for grouped fields. EVERY projection view that appears as a facet needs its OWN metadata extension — the root extension covers root list / object page only; without child extensions on the projections referenced by @UI.facet[].targetElement, those facets render with no labels. Activate the extension after creation; the projection view does not need re-activation unless its DDL changed.'
