description: 'Behavior Definition (BDEF) rules for a RAP managed BO with draft and strict (2). Per entity declare: authorization (root = `authorization master ( instance )`; child = `authorization dependent by _Root`), lock (root = `lock master total etag LocalLastChangedAt`; child = `lock dependent by _Root`), draft table (`draft table z##_<name>_d`), ETag (`etag master LocalLastChangedAt` on root; inherited on child), UUID numbering (`field ( numbering : managed, readonly ) <Key>;`). Draft actions (root only, all five required — missing Discard fails activation): Edit, Resume, `Activate optimized`, Discard, `determine action Prepare`. Mapping must be EXPLICIT per field (`{ Uuid = uuid; Matnr = matnr; MaterialType = mtart; … }`), never `corresponding` — that produces 40+ warnings and breaks persistence. No mapping section for draft tables. For BOs that reference another BO add `with cross associations;` to the BDEF header, otherwise "uses an obsolete implementation". Activate BDEF + BIMP together via ActivateBehaviorDefinition.'
