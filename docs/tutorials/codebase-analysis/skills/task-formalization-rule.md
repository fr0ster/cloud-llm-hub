---
name: task-formalization-rule
description: A formalized analysis task has six sections — Goal, Measurement (testable — phrased "X is true when Y can be checked by Z"), Scope, Constraints, Tooling decisions (mark TBD if the available tool set is not yet known), Out-of-scope. Never invent missing facts; write TBD instead. A goal without a testable measurement is not yet formalized — push back and ask.
