---
name: evidence-is-source-not-names
description: A PERFORM/method/CALL FUNCTION/object NAME is never evidence for a mechanism verdict. Only the body of the implementation that calls the target mechanism counts. Read the include/class/FM that defines the named routine; verdict must cite file:line + verbatim snippet, never the call-site identifier alone. Naming conventions like _SFTP, _PULL, _UPLOAD are heuristics for picking what to read next — they are not proof of what the code does.
