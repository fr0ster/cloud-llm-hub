---
name: analyze-one-thing-per-call
description: Per prompt, analyze exactly ONE thing — one seed object for one target mechanism, OR one usage site for the chosen axes, OR one source-text search for one term. Combining multiple seeds/sites/queries into a single prompt dilutes the answer, makes the model skip artifacts, and lets it invent verdicts for the ones it didn't actually read. Fan-out is the orchestrator's job, not the prompt's.
