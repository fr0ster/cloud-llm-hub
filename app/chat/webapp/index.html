Format

Help

Type, press Enter. That's it.

  • Type in the input box at the bottom.
  • Send or Enter — submit the message.
  • CLR — wipe history and start a fresh session.
  • LOG — download the current session as text.
  • STATUS — green idle, yellow streaming, red error.
  • Long answers stream live. Wait for STATUS to turn green again.

Pick what runs the answer.

  • LLM dropdown — the main model that answers you.
  • CLASSIFIER dropdown — small model for routing (advanced; usually leave default).
  • EMBEDDER — read-only, set at deploy.
  • MODE — read-only, current pipeline mode.
  • Switch LLM any time. The new pick applies to your next message.

Tell the chat which SAP system to use.

  • DEST dropdown — pick the SAP destination.
  • ↻ next to DEST — refresh the destination list.
  • SAP button (footer) — open the override form.
  • Override Login + Password — run as your own SAP user.
  • Leave override empty — use destination defaults.
  • Wrong creds? STATUS turns red on the next SAP call.

Your private knowledge for the chat.

  • MANAGE — opens the collection editor.
  • NEW COLLECTION — create one. Pick scope user (private, persists across sessions) or session (private, wiped on logout / clear chat / destination reconnect).
  • UPLOAD FILE — add one or more .txt/.md/.csv/.json/.yaml/.xml/.log files; each one is chunked automatically and shown in the document list as a single row regardless of chunk count. Pick multiple files in the picker and they upload sequentially.
  • + ADD — add one record by hand (paste text, optional id and tags).
  • SEARCH — find records inside a collection.
  • DL on a record — download it as a file (use this to back records up).
  • UPLOAD a saved file in MANAGE — restore records into a collection.
  • Records survive across sessions; collections do not always — back up DL files for anything you cannot afford to lose.
CONNECT TO SAP
Choose a destination and enter your ABAP user. Required before using the chat. To change the destination later, log out and back in.
